# Weather App 🌦️

A responsive weather forecasting web application built with React and the OpenWeatherMap API. The application allows users to search for a city and view its current weather information.

## Features

- 🌍 Search weather by city
- 🌡️ View current temperature
- ☁️ View current weather conditions
- 💧 View humidity
- 💨 View wind speed
- 📱 Responsive user interface

## Tech Stack

- React.js
- JavaScript
- HTML5
- CSS3
- OpenWeatherMap API
- Vite
